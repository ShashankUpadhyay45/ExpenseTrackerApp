# SpendSage 💸

SpendSage is an advanced, offline-first PWA expense tracker featuring Tesseract.js OCR receipt scanning, custom category budgets, bank CSV importing, and a 365-day activity heatmap.

### 🔴 [Live Demo (Vercel)](https://expensetrackerapp.vercel.app/) 
*(Note: Replace this link with your actual Vercel deployment link if it differs)*

## ✨ Features

- **Tesseract.js OCR Integration**: Scan and extract amounts/dates from physical receipts automatically.
- **Custom Budgets**: Set spending limits per category with progress bars.
- **CSV Import & Export**: Bulk import your bank statements instantly.
- **365-Day Activity Heatmap**: GitHub-style activity graph visualizing your spending frequency.
- **Bill Tracking**: Automatically separate "Upcoming" vs "Paid" recurring monthly bills.
- **Progressive Web App**: Fully installable offline PWA with `manifest.json` and service workers.
- **Data Persistence**: Everything is safely encrypted and stored in `LocalStorage`.

## 🛠️ Technologies

- HTML5 & CSS3
- JavaScript (Vanilla)
- LocalStorage API
- Tesseract.js CDN
- Chart.js

## 🚀 Local Setup

Since this is an offline-first app, simply clone the repository and open `index.html` in your web browser. No `npm install` or build steps required!
